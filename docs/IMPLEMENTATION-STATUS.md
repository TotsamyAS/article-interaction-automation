# Состояние реализации

## M3/M4/M5 и сквозной Task Mining — 29.09.2026

Этот раздел актуальнее записей ниже от 22–23.09. M4/M5 больше не являются отложенными.

- **M3:** переведён с OpenRouter на RouterAI (`https://routerai.ru/api/v1`), модель `google/gemma-4-26b-a4b-it`, `temperature=0`, `seed=0`, strict JSON Schema → общий `Query` → прежний детерминированный executor. Runtime prompt — `m3-query-v3`. Секрет переименован в `ROUTERAI_API_KEY`.
- **M4:** browser Web Speech API (`SpeechRecognition`/`webkitSpeechRecognition`, `ru-RU`) → распознанный текст → тот же M3 RouterAI compiler → тот же executor. Transcript read-only; при ошибке распознавания запись повторяется. Firefox получает предупреждение после входа и не может стартовать M4. Серверного ASR и хранения аудио нет.
- **M5:** backend agent по протоколу `benchmarks/m5_agent_benchmark.ipynb`: RouterAI/Gemma, 7 tools (`search_tasks`, `filter_by_field`, `group_by`, `aggregate`, `find_extremum`, `sort`, `export_result`), tool loop до 12 LLM-шагов. Наблюдаемая trajectory пишется в `m5_agent_runs`; финальный `Query` проходит общий executor/эталон.
- **Task Mining:** обязателен во всех M1–M5. Сохраняются браузерные input/pointer/scroll/focus/navigation и `request_started/request_finished`; M4 дополнительно пишет `speech_started/speech_finished`. Речь считается активной пользовательской работой; время системного ожидания вычитается. M5 trajectory хранится отдельно и не заменяет Task Mining.
- **Analytics:** schema v5; XLSX/ZIP получили `agent_runs`.
- **M5 benchmark:** отдельный пятиповторный прогон: 15 задач × 5 = 75 запусков, 73 успешных, 2 ошибки, **97,33%**. Это инженерная проверка agent pipeline; не пользовательская метрика M5. Исходный загруженный notebook содержит более ранние outputs, поэтому результат 73/75 здесь отмечен как отдельный прогон, без подмены notebook-output.

Локальная backend-проверка после изменений: `python -m pytest -q -p no:cacheprovider tests --ignore=tests/test_invitation_cli.py` → **97 passed**. `test_invitation_cli.py` исключён только потому, что его shell-wrapper в этой среде рассчитан на контейнерный путь `/app`; это не тест M3–M5.
