01 / Получить свежий снимок

Данные обрабатываются только в этом окне

Войдите на сервер по своему приглашению исследователя, скачайте ZIP и откройте его здесь. При повторной выгрузке вход обычно уже сохранён браузером.

Перетащите выгрузку сюда

Полный export.zip, trials.csv или JSON из /api/analytics

Как работает скачивание

Кнопка открывает /api/analytics/export.zip в новой вкладке с авторизацией сервера. Если получен 401/403 — сначала войдите по приглашению роли researcher. Используйте тот же браузер и адрес сервера, что при входе. При необходимости выберите контекст исследователя через несекретный UUID access: . Ссылку-приглашение сюда вводить не нужно. Локальная страница не читает cookie, не выполняет SSH и не обходит CORS. Для нового снимка повторите скачивание и импорт.

Ожидание выгрузки. Графики появятся после импорта.

02 / Обзор результатов

Снимок не загружен

Результаты по участникам

Участник определяется по participant_code. Несколько сессий суммируются. Процент рядом с кодом — выполненные (зелёные) пробы / все пробы в текущем фильтре.

Результаты по режимам

Суммы — по выбранным пробам режима. Среднее, минимум и максимум — на одну пробу. Время от старта до завершения включает ожидание системы и все попытки; перерывы между пробами не входят. Попытки включают все отправки на итоговую проверку, в том числе неудачные до успеха. Активные и неначатые пробы исключены; пропуски не заменяются нулями.

Активное пользование · минуты на пробу

Tuser_active_ms — оценка активности по журналу действий: исключает зарегистрированную потерю фокуса, системное ожидание и длинные паузы между действиями. Время размышления без действий может не войти. Отсутствующие значения не подменяются общим временем.
