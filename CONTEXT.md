# Эксперимент человеко-машинного взаимодействия

Термины экспериментального стенда по разделам 4–5 `docs/article_project.docx`.

## Термины

**Запись набора данных**: задача проекта банковского приложения, над которой участник выполняет фильтрацию и другие операции. Всего в экспериментальном наборе 120 записей.

**Экспериментальная задача**: инструкция участнику с определённым уровнем сложности и ожидаемым результатом. Имеет один из 15 вариантов C1a–C3e.

**Сессия**: прохождение одним участником пяти блоков режимов; основная сессия содержит 15 проб.

**Блок режима**: три последовательные пробы C1 → C2 → C3 в одном режиме взаимодействия.

**Проба**: выполнение одного варианта экспериментальной задачи в одном режиме. Может включать несколько попыток и завершается успехом либо достижением лимита.

**Попытка**: один отправленный на итоговую проверку результат участника. Промежуточная настройка фильтров не считается попыткой.

**Эталон**: заранее определённое множество идентификаторов записей и, когда требуется, значение агрегата для экспериментальной задачи.

**Фактические метрики**: измерения реально произошедших действий и результатов пробы.

**Метрики для анализа**: показатели для обработки результатов статьи, включающие отдельно назначенные штрафные значения незавершённых проб.

**Код участника**: псевдоним испытуемого, связывающий его сессии и результаты без хранения ФИО и email.

**Приглашение**: индивидуальная многоразовая ссылка, позволяющая войти как тот же участник и продолжить работу с сохранённым прогрессом.
